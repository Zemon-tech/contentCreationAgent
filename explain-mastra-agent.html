End-to-End System Topology

The Aggregator Agent resides in the Mastra Node.js engine, while the Design Agent runs in an isolated Python/ComfyUI environment. They communicate strictly over a decoupled REST interface with workspace artifact synchronization.

Step-by-Step Execution Lifecycle

How an industry event transitions from raw internet data to verified intelligence, and finally into a polished Instagram carousel.

Phase 1: Ingestion & Radar Triage

The aggregatorAgent runs with a strict "Search-Then-Read" loop:

  • Calls getCurrentTimeTool first to establish strict ground-truth date.
  • Sweeps RSS feeds and searches Exa with category: news.
  • Enforces Freshness Hierarchy: event_at vs discovered_at. An old article found today is marked STALE (capped at score ≤ 40).
  • Enforces Evidence Tiers: T0_PRIMARY (official releases/blogs) down to T3_COMMUNITY (Twitter/Reddit discovery only).
  • Executes strict Decision Gate: POST_NOW | WORTH_COVERING | MONITOR | DO_NOT_POST.
Phase 2: Hand-off to Design Agent

When a user requests a post or a story achieves POST_NOW:

  • Agent is forbidden from writing raw manual social posts in chat.
  • Selects createPostFromContent (if story text exists) or searchNewsAndCreatePost (if only a topic was provided).
  • Passes layout format (single vs carousel) and template (e.g. tech-announcement, 360labs-news).
  • The tool bridges to submitDesignJob() firing a POST /jobs request to the Python FastAPI daemon.

Architectural Critique & Production Inefficiencies

An unvarnished assessment of the current design patterns, latency bottlenecks, and optimization opportunities.

1. Tight Filesystem Coupling in Cross-Process Deliverables

Issue: In copyDeliverablesToWorkspace(), the Mastra server relies on direct local disk access (fs.copyFileSync) pointing to S:/tmp/design-agent/output.

Risk: This assumption instantly breaks if the Design Agent container runs on an independent cloud node, GPU cluster (e.g. RunPod), or remote host. The Mastra tool fails with ENOENT because it expects local filesystem path parity.

Remedy: The Design Agent's GET /jobs/{id} endpoint should return pre-signed S3/Blob URLs or serve the artifacts as direct HTTP streams rather than forcing local folder copy operations.

2. Synchronous Polling Loop in Agent Tool Execution

Issue: waitForDesignJob() executes a blocking while loop with setTimeout(..., 2000) for up to 180 seconds within the Mastra tool execution handler.

Risk: During heavy ComfyUI diffusion runs (e.g., rendering 5 carousel slides), the Mastra agent execution thread is kept hanging. If an upstream proxy or client has a 30s or 60s gateway timeout, the connection is dropped mid-generation.

Remedy: Adopt Server-Sent Events (SSE) or webhook callbacks: have the tool register a callback URL on Mastra, return an immediate acknowledgment, and notify Mastra upon completion.

3. Token Budgeting & Sandboxed Serving Route (Positive Pattern)

Setting maxOutputTokens: 8000 specifically prevents completion truncation during batched schema serialization (saveStories). Furthermore, registering postAssetRoute with regex validation (JOB_ID_PATTERN and SLIDE_FILENAME_PATTERN) properly protects against path-traversal attacks while serving rendered images in Studio.
