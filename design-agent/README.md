# Design Agent

Turns raw content text into Instagram-ready images (single or carousel) from hand-authored HTML/CSS templates. Imagery for template slots is generated by ComfyUI; copy is generated by an LLM (Sarvam `sarvam-105b` with strict structured outputs) and composited into templates via headless Chromium (Playwright) and Pillow. The system produces files only — it never publishes directly to Meta/Instagram.

The full design contract and architectural specifications live in [`spec.md`](./spec.md) and [`PLAN.md`](./PLAN.md).

---

## Architecture & Pipeline

```
[ POST /jobs ]
      │
      ▼
 1. Planner (Sarvam AI)
    - Dynamic strict JSON schema derived from hand-authored TemplateManifest
    - Slot character caps (max_chars) & banned-word scanning (brand.yaml)
    - Single retry on validation failure; never silently truncates copy
      │
      ▼
 2. Image Engine (ComfyUI)
    - API-format workflow injection via companion .map.json files
    - Single-slot GPU serialization lock (prevents CUDA OOM on host)
    - WebSocket execution listener + PNG artifact download
      │
      ▼
 3. Compositor (Playwright Chromium + Pillow)
    - Jinja2 template hydration with brand tokens & assets
    - Headless Chromium screenshot of #canvas at exact target resolution
    - Text overflow auto-fit: downscales font-size to floor; never edits copy
    - Pillow normalization: exact dimensions, sRGB color profile, JPEG <= 1.4 MB
      │
      ▼
 4. Assembler (Disk Output)
    - Writes OUTPUT_DIR/<job_id>/ with slide_NN.jpg, caption.txt, post.json, plan.json
    - Validates Instagram technical requirements (resolutions, file sizes, hashtags)
```

## Local Setup

```bash
# 1. Install dependencies into isolated .venv
uv sync

# 2. Install Playwright Chromium browser
uv run python -m playwright install chromium

# 3. Configure environment variables
cp .env.example .env
```

Edit `.env` to configure your keys:
```ini
DESIGN_AGENT_API_KEY="dev-secret-key-change-in-prod"
SARVAM_API_KEY="your-sarvam-api-key"
COMFYUI_BASE_URL="http://127.0.0.1:8188"
COMFYUI_WS_URL="ws://127.0.0.1:8188/ws"
ENVIRONMENT="development"
LOG_RENDERER="console"
```

## HTTP API Reference

All endpoints except `GET /health` require the `X-API-Key` header.

### 1. Health Check
`GET /health` (Public)
Checks application liveness and whether ComfyUI is reachable.
```json
{
  "status": "ok",
  "comfyui": "reachable"
}
```

### 2. Submit Generation Job
`POST /jobs` (Protected)
```json
{
  "content": "Patience as an editorial method in knowledge systems. Knowledge done well is deliberate and careful.",
  "format": "single",
  "aspect_ratio": "4:5",
  "template_id": "keilhq-editorial",
  "max_slides": 5
}
```
**Response (202 Accepted):**
```json
{
  "job_id": "d6e32d56-745a-4cb6-bb50-a93144a958e9",
  "status": "queued"
}
```

### 3. Poll Job Status
`GET /jobs/{job_id}` (Protected)
Status transitions: `queued` → `planning` → `generating_images` → `compositing` → `done` | `failed`.

**Response when done (200 OK):**
```json

  "status": "done",
  "post": {
```

## Output Files Structure

On job completion, deliverables are written under `OUTPUT_DIR/<job_id>/`:

```
output/<job_id>/
├── slide_01.jpg       # 1080px wide sRGB JPEG <= 1.4 MB
├── slide_02.jpg       # Additional carousel slides (if carousel)
├── caption.txt        # Copy-paste ready: caption + blank line + #hashtags
├── post.json          # Machine-readable post metadata and validation reports
└── plan.json          # Validated PostPlan from planner stage
```

## Templates & Fonts

Templates are located in `templates/<template_id>/`:
- `manifest.json`: Defines supported formats, aspect ratios, and character limits for text/image slots.
- `template.html.j2`: Jinja2 template containing the `#canvas` root element.
- `style.css`: CSS styling using brand tokens and responsive typography rules.

### Brand Fonts & Fallbacks
- Place custom brand font files in `templates/_shared/fonts/` (see [`templates/_shared/fonts/README.md`](templates/_shared/fonts/README.md)).
- On Linux VMs, install Noto fallback fonts to guarantee rendering of any Unicode glyph or emoji:
  ```bash
  sudo apt-get install -y fonts-noto-core fonts-noto-cjk fonts-noto-color-emoji
  ```

## Deployment Hardening (Linux GPU VM)

### 1. Docker Deployment (Recommended)
Build and run using the provided `Dockerfile` and `docker-compose.yml`:
```bash
docker compose up -d --build
```

### 2. Manual VM Setup
- **Playwright Chromium**: Launch arguments in `app/main.py` include `--no-sandbox` and `--disable-dev-shm-usage` to run reliably in containerized or resource-constrained environments.
- **GPU Lock Serialization**: Diffusion requests to ComfyUI are protected by an internal process-wide `asyncio.Lock` to guarantee single-slot execution and prevent CUDA Out-Of-Memory crashes.
- **Rendering Semaphore**: Playwright Chromium page concurrency is capped via `RENDER_CONCURRENCY` (default `2`) to bound memory footprint during heavy bursts.
- **ComfyUI Isolation**: ComfyUI runs as an independent external service on `127.0.0.1:8188`. The design agent connects strictly as a client.
