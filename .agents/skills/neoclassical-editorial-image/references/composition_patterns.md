# Composition Patterns A–G (pick ONE, vary across outputs)

Poster-like, strong hero, large graphic shapes, intentional asymmetry, controlled
chaos, clear FG/MG/BG, overlap, large negative space, strong silhouette, scale surprise.

- **A Hero + symbolic object:** large hero + one charged object (e.g. bust + satellite).
- **B Classical figure + modern tech:** scholar/statue operating device/machine.
- **C Object collision:** two oversized objects colliding mid-frame (clock + server rack).
- **D Central subject + small symbols:** large center + orbiting vignettes/icons.
- **E Classical landscape + modern intrusion:** engraved landscape pierced by cable/data monolith.
- **F Diagrammatic collage:** old diagrams/charts rewired with glowing nodes.
- **G Surreal scale shift:** miniature figures on giant book-chip / giant hand holding city.

Always specify: hero scale, FG/MG/BG layers, asymmetry axis, negative-space location,
eye path (1st/2nd/3rd read). Never reuse same pattern blindly.
