# Lighting & Texture Taxonomy (controlled vocabulary)

Prefer these exact terms so prompts stay transferable across Higgsfield Soul, Flux, SDXL, Midjourney.

## Kelvin table

| Value | Name | Use cue |
|---|---|---|
| 2700–3200K | Warm tungsten / practical lamp | Domestic night, cozy, amber skin |
| 3400–3800K | Warm morning sun through window | Golden slats, terracotta bounce |
| 4200–4500K | Mixed interior / fluorescent-warm | Office-realist, candid |
| 5000–5600K | Daylight / overcast / flash | Neutral editorial, flash-freeze (`flash ~5500K`) |
| 6000–7000K | Cool shade / blue hour | Melancholy, tech-clean |

## Light quality + ratio

- `soft wrap-around diffused (1.5:1–2:1)` — overcast, beauty studio, seamless e-commerce
- `naturalistic soft-directional (2.5:1)` — window drape, linen scrim
- `moody cinematic (3:1–4:1)` — side-key, falloff into shadow floor
- `hard direct flash (4:1–8:1)` — on-camera flash, sharp nose shadow, wall falloff hotspot
- `harsh noon sun (8:1+)` — crunchy nose/chin shadows (rare; usually avoid)

Shadow edge words: `feathered / crisp / crunchy / lifted-faded / crushed-deep`. Catchlight words: `round flash catchlight / window-rectangle catchlight / absent`.

## Film stocks & finishes (pick one)

- `Kodak Portra 400` — warm creamy skin, fine grain, lifestyle/editorial
- `Kodak Vision3 500T (5219)` — tungsten-balanced cine, deep blacks, amber halation, night interior
- `Kodak Vision3 250D (5207)` — daylight crisp, true primaries, crowd/day exterior
- `Kodak Tri-X 400` — punchy B&W-ish grain, gritty documentary
- `Fuji Eterna 500` — desaturated pastel shadows, arthouse softness
- `iPhone direct-flash digital` — flat, sharp, slight shutter lag softness
- `Old-smartphone / Y2K digicam` — compressed highlights, noisy shadows, built-in flash blowout
- `Xerox/halftone/risograph analog` — handmade print dots, scratched ink, ripped-paper seams

Grade LUTs: `Kodak 2383 Print`, `matte-faded-blacks`, `teal-shadows/amber-skin split`, `bleach-bypass desat`, `high-saturation commercial pop`.

## Texture nouns (need 3+; pair material + light response)

Skin: `visible pores`, `peach fuzz`, `subsurface-scatter sheen`, `flash-sheen forehead`. Fabric: `coarse canvas weave`, `ribbed cable knit`, `selvedge denim twill`, `moquette transit velour`, `sheer linen drape`, `nylon windbreaker crinkle`. Surface: `glazed ceramic grout`, `brushed stainless lines`, `weathered splintered timber`, `knurled chrome`, `matte plastic`, `glass transparency`, `crusty bread crumb`, `terracotta clay`.

## Grain / halation / post traces

Grain: `ultra-fine 35mm`, `fine organic`, `punchy Tri-X`, `digicam chroma noise`. Halation: `golden-red window bloom`, `amber practical-lamp bloom`, `blue anamorphic streak (use sparingly for stills)`. Traces: `dust motes`, `light-leak edge`, `chromatic aberration fringe`, `halftone dots`, `scan scratches`, `compression banding (old-smartphone only)`.
