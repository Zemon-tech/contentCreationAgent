# Metaphor Engine

Derive in order: ARTICLE/IDEA → ABSTRACT CONCEPT → VISUAL METAPHOR → HERO →
SUPPORTING OBJECTS → ENVIRONMENT → HISTORICAL↔MODERN CONTRAST.

Sentence stems: "The image is really about ___." → "The best visual metaphor is ___."

Example: idea "knowledge work automated" → concept "human knowledge transformed by
machines" → metaphor "classical scholar feeding scrolls into futuristic machine
extruding glowing digital structures" (historic: scholar+scrolls+engraving;
modern: machine+digital geometry).

Novelty rule: avoid robot-with-laptop / person-working-faster. Prefer:
library shelves → neural branches; figure wrestling clockwork of calendars/documents/
glowing UI; scholar navigating machine landscape. Curiosity > literalism.
For articles: 3–5 internal candidates, pick strongest (clarity, originality,
house fit, composition, impact, text-independence). Expose ranking only if asked.
